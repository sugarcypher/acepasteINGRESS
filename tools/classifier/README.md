# The learned pass: how the classifier is built

The engine's classifier (`packages/core/src/classifier.ts`) is a logistic regression over two hashed bags: word
1-2-grams and character 3-5-grams inside word boundaries, 2^18 columns each. The weights ship inside the
package as `classifier-model.ts` (int8, about 0.7 MB). It has no runtime dependency and scores a text in well
under a millisecond, on the machine.

| file | what it does |
|---|---|
| `build_training_set.py` | downloads the training sources, removes everything used for scoring, writes `train.jsonl` |
| `hard_negatives.py` | generates benign text that uses attack vocabulary innocently, and ordinary present-day email |
| `train.py` | trains, picks the model's own line on a validation split, prints scores, exports the model |

```sh
python3 -m venv ~/ingress-ml && ~/ingress-ml/bin/pip install scikit-learn pandas pyarrow numpy
W=~/ingress-classifier
~/ingress-ml/bin/python tools/classifier/hard_negatives.py $W/hard-negatives.jsonl
~/ingress-ml/bin/python tools/classifier/build_training_set.py $W --exclude <pint-sets> --exclude <email-dev> --exclude <email-holdout>
~/ingress-ml/bin/python tools/classifier/train.py $W --eval <pint-sets> --eval <email-dev> --out packages/core/src/classifier-model.ts
npm run build && npm test          # the parity test checks the TypeScript featurizer against the trainer
```

Every script prints counts and rates, never text: half the data is attacks.

## What the classifier may decide

It knows a text is *about* instructions to an assistant, not whether the text issues them, so its authority
depends on what it is reading (`classifier.ts`):

- **Hidden text, anywhere:** decides at 0.9. Nothing is reported in text nobody is shown.
- **Messages** (email, chat message, notification, event): decides at 0.8.
- **Plain text of unknown kind:** decides at 0.85.
- **Visible text of a page or document:** recorded on the receipt, decides nothing. Writing about prompts is
  common there, and the classifier scores a news article that quotes an attack as high as the attack.
- Text is also scored with its quotations removed, and the lower score counts.
- Alone it makes content *suspect* (refused, and a person may override), never hostile. A rule agreeing with it
  can.

## Known limits

- **One language does not carry to another.** No Turkish attack was in training and Turkish attacks are caught
  no better than before (3.3%). A multilingual embedding model would transfer; it is not built.
- **It reads the first 4,000 characters** of a text as trained, and later stretches in windows.
- **Generated training data is template-made.** It taught the model that the vocabulary alone is not the attack;
  it is not a sample of real text.
- **A determined attacker can craft text that scores low.** It is one pass beside the rules, hidden-text checks
  and the action broker, not a wall on its own.
